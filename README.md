## 運用ルール（Claudeが実行・人は覚えなくてよい）

1. **フォルダ名は2桁の連番のみ**（`01`, `02`, …）。名前を考える必要はない
2. **採番はClaudeが自動で行う**：リポジトリ直下の数字フォルダの最大番号＋1を新番号にする。濵田・山口どちらが依頼しても衝突しない
3. 各作品フォルダには `index.html` を置く（画像は `assets/` 配下）
4. 公開作業の最後に、Claudeがこの台帳（作品名・内容・作者・作成日・URL）を必ず更新する
5. 修正ログ自動記録（Make）の対象外なので、PRは不要。直接コミットでよい
6. 画像・動画はGitHub Pagesの制約上、1ファイル25MB未満・合計1GB未満に収める
